## Orientation (read once)

Proofline is an evidence-backed research site for native Robinhood Chain (chain id 4663) DeFi projects.
Everything the site shows comes from files under `content/` (YAML + Markdown), validated by JSON Schema and
compiled into `build/derived.json` by `npm run score`. The site in `site/` renders those files. Read
`README.md` (all of it — 10 minutes) and `PRD.md` §6 (rating system) and §7 (evidence classes, writing
standard) before touching content.

Commands (repo root, Node 20+; `npm ci` once, and `cd site && npm ci` once):

| command | what it proves |
|---|---|
| `npm test` | schema + cross-reference validation, voice/conduct lint, scoring tests — must be green |
| `npm run validate` | validation only; expect `0 error(s)`; warnings that exist on `main` are fine |
| `npm run validate:release` | adds launch blockers; today `main` reports 12 errors that are known (see Task 7) |
| `npm run score` | prints one line per project; writes `build/derived.json` |
| `cd site && npm run typecheck && npm run build && npm run smoke` | site compiles and every route answers 200 |

Rules that bind every task:

1. **Never edit `PRD.md`.** It is the owner's document.
2. **Never push to `main`.** Work on the branch each task names, push it, open a PR to `main` (Task 1 updates an existing PR). A human merges anything that touches `content/projects/**`, `content/accounts.yaml`, `content/census.yaml`, scoring, or `content/changelog.yaml`.
3. **Evidence classes** (`PRD.md` §7.1): `verified` only for facts reproduced from onchain data (an explorer page, an RPC read at a pinned block, the official contracts registry) and the source `excerpt` must state what was observed. Docs, X posts, DefiLlama, GitHub, and the analyst's own reading are `claim` (or `inference`). Unknown = no credit.
4. **Every fact cites a ledger id** (`S1`, `S2`, … in `content/sources/<slug>.yaml`). Never renumber existing ids; append new ones after the highest id in that file. Fill every required field of a source entry (`id, url, publisher, kind, accessed_at, claim, excerpt, hash, archive_url, researcher, available`); `hash`/`archive_url` may be `null`; `researcher: harsharn10`.
5. **Voice** (`PRD.md` §7.3): plain, dated, sourced; no hype, no accusations, no conduct words, no "the desk"/"Grok" in reader-facing text (changelog `detail`, research prose, summaries). `npm test` runs the lint and fails on violations.
6. **Changelog**: every content change that a reader would notice gets an entry in `content/changelog.yaml` (copy the shape of the last entries; `reviewer: harsharn10`; `severity` Info / Review / Material as the existing entries use it).
7. Commit prefixes in use: `content:`, `score:`, `site:`, `intake:`, `docs:`, `ci:`. One PR per task.

Line numbers below were taken at the commits named; if a file moved, grep for the quoted text.
